# Sensei Overworld v0.4 assets

Production integration assets derived from the Product Owner-approved isolated `Sensei_Overworld_v0.4` package.

- Seasonal landscapes are optimized WebP derivatives of the approved 2172 × 724 masters.
- Lighting, weather, sprite, and terrain files preserve the approved package assets.
- Weather data displayed with these assets is supplied by Open-Meteo under CC BY 4.0 for this private non-commercial household application.

The original masters, generation method, manifest, and visual-quality report remain in the isolated v0.4 package outside the application repository.
